# 🐍 Python Course | كورس تعلم البايثون

مرحباً بك في مستودع كورس لغة بايثون. يحتوي هذا المستودع على التطبيقات والحلول الخاصة بالدروس والتكليفات.

## 📂 محتويات المستودع (Repository Contents)

* **First Folder:**
  In the "First" folder, you will find the solutions for the course assignments approved by Elzero Web School. These assignments cover lessons 1 to 95.
  *(في مجلد First ستجد حلول تكليفات الدروس المعتمدة من موقع الزيرو، والتي تمتد من الدرس الأول إلى رقم 95)*

* **OOP Folder:**
  This folder contains solutions for the Object-Oriented Programming (OOP) series assignments from Elzero Web School.
  *(يحتوي هذا المجلد على حلول تكليفات سلسلة البرمجة كائنية التوجه OOP من موقع الزيرو)*

* **Regular Expressions Folder:**
  This folder includes solutions for the Regular Expressions (Regex) series assignments from Elzero Web School.
  *(يحتوي هذا المجلد على حلول تكليفات سلسلة التعبيرات المنتظمة Regular Expressions من موقع الزيرو)*
